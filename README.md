# Student Expense Tracker

A lightweight student budgeting dashboard for tracking daily expenses and monthly spending.

## Features

- Add expenses with amount, category, and date
- Set a monthly budget
- See spent and remaining totals
- Spending breakdown by category
- Recent expense history
- Delete individual expenses or clear history
- Responsive mobile layout
- Data persists in browser localStorage

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Roadmap

Next versions can add charts, monthly history, CSV export, recurring expenses, authentication, and cloud/database sync.
